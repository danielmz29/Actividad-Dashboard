## Archivos del proyecto

- `index.html`: página principal con el resumen.
- `productos.html`: muestra la lista de productos.
- `movimientos.html`: muestra un gráfico sencillo de movimientos.
- `reportes.html`: muestra información general del inventario.
- `estilos.css`: contiene los estilos de todas las páginas.

Lo hice de esta manera para poder cambiar entre paginas de mejor manera

## Temas utilizados

- HTML5
- CSS
- CSS Grid
- Flexbox
- Variables CSS
- `:hover` y `:focus`
- Media query para móvil
- Etiquetas semánticas y atributos básicos de accesibilidad

## Diseño

En computador se utiliza una barra lateral para navegar entre las páginas.

En celular la barra lateral desaparece y aparece un menú desplegable.
